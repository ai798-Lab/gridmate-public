TRANSPARENT BY DESIGN

关于隐私，说清楚。

更新日期：2026 年 9 月 20 日 · 适用于窗多多 0.3.4

窗多多 在你的 Mac 上整理窗口。App 的本地行为和官网使用的托管服务是两回事，我们分别说明。

1. App 访问哪些信息

获得辅助功能权限后，窗多多 读取应用和窗口的元数据，例如所属进程、窗口位置、尺寸、状态及窗口控件，并通过调整位置和尺寸完成排布。诊断命令还可能读取窗口标题。窗口排布不依赖截图，也不读取文档正文。

2. 哪些内容保存在本机

布局、边距、间距、排除的 App 等设置保存在本机 SnapTiler 的 Application Support 目录，语言选择保存在应用偏好中。撤销所需的位置和尺寸信息只保留在当前运行进程的内存里。当前 App 没有账号体系、广告 SDK，也没有上传这些信息的代码。

3. 诊断与问题反馈

Release 构建关闭了记录鼠标交互的文件调试日志。macOS 仍可能保留启动、排布数量和错误等运行日志。开发构建和手动执行的诊断命令可能输出更详细的信息。反馈完全由你主动发起，请先移除截图或日志里的窗口标题、私人文件名和敏感内容。公开 GitHub Issue 中的信息对所有人可见。

4. 官网与下载服务

本网站不添加统计脚本、广告追踪器或外部字体服务。字体、图标与插画均随本站提供。网站仅用浏览器本地偏好记住你选择的官网语言；禁止存储不会影响访问。使用 GitHub Pages 托管时，GitHub 会为安全目的记录访问者的 IP 地址。安装包下载和问题反馈也由 GitHub 提供，适用其隐私声明。

5. 你可以如何控制

你可以随时在系统设置中撤销 窗多多 的辅助功能权限，或关闭登录时启动。删除 App 不一定删除本地设置。也可在「关于」中关闭自动检查更新。如需移除偏好，应先退出 App，再只清除 窗多多 对应的配置与偏好文件。清除本网站的浏览器存储，可重置官网语言选择。

6. 更新检查

当前版本提供默认开启、可关闭的每日更新检查：软件运行时读取 GitHub Pages 上的公开版本清单，不发送窗口数据、日志、设备标识或账号信息。检查使用临时网络会话，不保存 Cookie；GitHub 仍可接收 IP 地址等正常连接信息。提醒、跳过版本与检查时间保存在本机。下载安装由用户自行发起，未安装新版的旧用户不会获得此功能。

7. 联系与变更

一般问题可通过 窗多多 的公开支持入口反馈，请勿在公开区域提交个人资料。也可在微信搜索公众号 ai798Lab 留言；发送的内容适用微信的隐私规则。这份说明描述当前版本；如果未来引入账号、支付或数据分析，需要在相关功能上线前更新说明及相应选择。
