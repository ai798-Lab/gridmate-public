SnapTiler 0.3.5

中文名称是「窗多多」，英文名称是 SnapTiler。这次更新统一了安装包、应用文件、程序、资源包和内部应用标识。

This release unifies the installer, app, executable, resources, and application identity under SnapTiler. The Chinese product name remains 窗多多.

安装与升级 / Installation

  1. 下载 DMG，将 SnapTiler.app 拖入「应用程序」。
  2. 退出之前的版本，然后从「应用程序」打开 SnapTiler。
  3. 首次使用时，按引导到「系统设置 → 隐私与安全性 → 辅助功能」允许新应用。此次应用标识已更新，即使之前授权过，也可能需要重新允许一次。

Open the DMG and drag SnapTiler.app to Applications. Quit the previous version before launching. This release has a new application identity, so Accessibility access may need to be granted again. Existing versions remain separate; new installations start with default preferences.

此版本包含 / Included

  • 21 种布局、最多 12 个窗口分区，32 个语言与地区选项。
  • 统一的中英文品牌、清晰的布局库与设置界面。
  • 窗口排列、当前窗口分区、撤销、拖拽吸附及本地偏好设置。
  • Developer ID 签名与 Apple 公证；安装包完整性校验见下载区。

需要 Apple silicon Mac。窗口排列受其他 App 的最小尺寸和当前显示器可用范围影响；不跨越其他桌面空间整理窗口。
